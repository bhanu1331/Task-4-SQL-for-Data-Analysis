#  Task 4: SQL for Data Analysis  

##  Objective  
The objective of this task is to perform **data analysis** using SQL queries on the `bike_rides_new` dataset. The analysis covers basic queries, aggregations, subqueries, joins, creation of views, and query optimization using indexes.  

##  Dataset  
- **Table Name:** `bike_rides_new`  
- **Key Columns:**  
  - `ride_date` → Date of the ride  
  - `ride_count` → Number of rides  
  - `season_number` → Season indicator  
    - 0 → Winter  
    - 1 → Spring  
    - 2 → Summer  
    - 3 → Fall  
  - `temp_1` → Temperature  
  - `humidity` → Humidity  

##  Tools Used  
- **Database:** MySQL  
- **Client Tool:** MySQL Workbench
